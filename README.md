# 💰 Smart Budget Dashboard

## 📌 Overview
Smart Budget Dashboard is a full-stack web application that helps users track their expenses, manage monthly budgets, and gain insights into spending patterns.

---

## 🚀 Features
- 🔐 User Authentication (Login/Register)
- 💰 Monthly Budget Tracking
- 📊 Expense Management (Add/Delete)
- 📈 Category-wise Trends (Line Chart)
- 🥧 Expense Distribution (Pie Chart)
- 🧠 AI-based Spending Insights
- 🔄 Reset Monthly Data

---

## 🛠️ Tech Stack (MERN)
- **Frontend:** React.js, Chart.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Tools:** Git, GitHub
